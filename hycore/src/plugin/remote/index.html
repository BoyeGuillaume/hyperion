What is Hyperion?

Hyperion is a workspace that combines an instruction IR, a core runtime engine, plugin infrastructure, Python bindings, and C FFI support. It is designed to make compilation, analysis, and execution experiments easy to build and extend.

Rust Workspace IR + Parser Plugin System Python API C FFI

Core Engine

`hycore` provides runtime services, extension loading, scheduling, and plugin hooks. It is the execution center of the project.

Instruction IR

`hyinstr` defines module/function/block structures, parsing, type checking, normalization, and verification workflows.

Interoperability

Native bindings are available through Python packages and a generated C header, enabling integration in heterogeneous systems.
